# Lines allowed in the -d unimp,guest_errors,invalid_mem log of a G1 shell
# boot, one extended regex per line: accesses to the stub windows that
# docs/device-map.md records, and nothing else. All are QEMU's
# unimplemented-device; rz-dmac and usbphy-ctrl keep written values
# (write-retaining stubs), the others read 0. The G0 windows, then the
# blocks the vendor kernel builds in where mainline builds modules.
^ravb-eth[01]: unimplemented device (read|write) 
^riic[013]: unimplemented device (read|write) 
^usb[01]-host: unimplemented device (read|write) 
^usbphy-ctrl: unimplemented device (read|write) 
^rz-dmac: unimplemented device (read|write) 
^tsu: unimplemented device (read|write) 
^(mipi-dsi|vspd|fcpvd|du): unimplemented device (read|write) 
^(ssi[01]|rspi1|canfd|adc|usb0-func): unimplemented device (read|write) 
^rpc-if(-wbuf|-dirmap)?: unimplemented device (read|write)
